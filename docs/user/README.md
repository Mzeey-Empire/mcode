# User docs

Task-oriented guides for people using Mcode, written in the product's voice.
No implementation details, no contributor tooling.

Each major feature gets one concise page or section: what it does, how to
start, and anything unintuitive. A settings path is useful; descriptions of
visible buttons, icons, layouts, or every UI state are not. Before adding
text, ask what task or decision it helps the user with.

See the [documentation rules](../../AGENTS.md#documentation) before adding pages.
